# The Tasting Room

A food and drink journal with an upscale Napa-estate look — recipes, wine, cocktails, restaurants, travel, and guides.

**Live site:** https://first2third.github.io/the-tasting-room/

## About this repo

This repository holds the public edition of The Tasting Room: a single static file, `index.html`, served by GitHub Pages. It is an export of the full app version, which runs in Muse with sign-in, Publisher Studio, real subscriptions, and a weekly newsletter.

## Please note

On this public edition, Publisher Studio, Analytics, and newsletter subscriptions are placeholders — nothing you enter is stored or sent. The reading list lasts only for the current visit.

## Updating the site

The site is edited in the Muse app version and re-exported here as `index.html` whenever it changes.
